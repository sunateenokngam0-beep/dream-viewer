เปลี่ยนไฟล์ในเครื่องให้กลายเป็นเว็บไซต์ออนไลน์

01 — รู้จักไฟล์ .txt

TXT คือไฟล์ข้อความธรรมดา ไม่มีรูปแบบตัวอักษรพิเศษ คุณสามารถสร้างด้วย Notepad ได้ และสามารถใช้ Notepad เขียนโค้ด HTML ก่อนบันทึกเป็นไฟล์ .html

  1. เปิด Notepad บน Windows
  2. พิมพ์ข้อความหรือโค้ดที่ต้องการ
  3. เลือก File → Save As
  4. หากต้องการเว็บ ให้ตั้งชื่อ index.html และเลือก Save as type: All Files
  5. เลือก Encoding: UTF-8 เพื่อรองรับภาษาไทย

02 — สร้างหน้า HTML ใน Dreamweaver

เปิด Dreamweaver เลือก Site → New Site แล้วเลือกโฟลเดอร์เว็บไซต์ จากนั้นสร้างไฟล์ HTML และใส่โค้ดตัวอย่างนี้

<!DOCTYPE html>
<html lang="th">
<head>
  <meta charset="UTF-8">
  <title>เว็บไซต์แรกของฉัน</title>
</head>
<body>
  <h1>สวัสดีชาวโลก!</h1>
  <p>ฉันกำลังเรียนสร้างเว็บไซต์</p>
</body>
</html>

บันทึกเป็น index.html แล้วเปิดไฟล์ผ่าน Chrome เพื่อตรวจสอบผลลัพธ์

03 — อัปโหลดขึ้น GitHub Pages

  1. เข้าสู่ระบบ GitHub แล้วสร้าง Repository ใหม่ เช่น dream-viewer
  2. เลือก Public และกด Create repository
  3. กด Add file → Upload files และอัปโหลด index.html
  4. กด Commit changes เพื่อบันทึก
  5. เข้า Settings → Pages
  6. ตั้ง Source เป็น Deploy from a branch, Branch เป็น main และ Folder เป็น /(root)
  7. กด Save แล้วรอให้ระบบเผยแพร่เว็บไซต์
  8. เปิดลิงก์ https://USERNAME.github.io/dream-viewer/ โดยเปลี่ยน USERNAME เป็นชื่อบัญชีของคุณ
